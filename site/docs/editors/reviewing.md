# Approving changes

Changes are approved by the **data owner**. Each editor's changes are
gathered into one **change request** (a GitHub pull request) called "Changes
from _editor_". GitHub emails you when one is opened.

You don't need to read any code. The change request's description lists
every change in plain English. It updates each time the editor saves.

1. Read the list of changes.
2. If something needs changing, ask the editor to change it in the editor.
   You can also comment on the change request.
3. When everything is right, choose **Files changed**, then
   **Review changes**, then **Approve** and **Submit review**.
4. Choose **Merge pull request**, or ask a maintainer to.

Approved changes appear on this site straight away, listed on the
[Changes](pathname:///changes/) page. They reach the teams that use the data
in the next release.
